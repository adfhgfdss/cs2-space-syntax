# 实验一 / 实验二 简明报告

数据：de_dust2 与 de_mirage 各 10 场职业赛（HLTV，含次级职业与资格赛），
共 3,255 次击杀。构形指标由 **depthmapX v0.9.1 命令行版**计算。
所有数字为实测值，无估算。

---

## 结论（三句话）

1. **实验一：方向对，强度弱。** 交火密度随整合度上升，但只有 Mirage 达到显著
   （ρ=+0.2759，p=0.000193）；Dust2 不显著（ρ=+0.0854，p=0.289）。
   Dust2 上真正有效的是**选择度**（ρ=+0.3133，p=0.0000682）。
2. **交火确实集中在高整合度轴线上。** 整合度最高的 20% 轴线承担了 Dust2 32.75%、
   Mirage 43.50% 的交火（随机基准 20%）；前 50% 分别承担 46.73% 与 72.65%。
3. **实验二：与预期相反。** 两种口径都显示 **Mirage 的可理解度更高**：
   轴线 R² Dust2 0.0284 vs Mirage 0.1039；VGA R² Dust2 0.4318 vs Mirage 0.8809。

## 实验一：构形敏感性（轴线 × 交火热点）

### 数据表（轴线级，已剔除 depthmapX 判为孤立的轴线）

| 指标 | de_dust2 | de_mirage |
|---|---|---|
| 有效轴线数 | 156 | 178 |
| 交火次数 | 1,530 | 1,722 |
| **整合度 × 交火密度** Spearman ρ | +0.0854（p=0.289） | **+0.2759**（p=0.000193） |
| 　Pearson r / R² / p | +0.1189 / 0.0141 / 0.139 | +0.2099 / 0.0441 / 0.00491 |
| 　回归斜率（次·米⁻¹ / 整合度单位） | 20.679 ± 13.912 | 54.981 ± 19.300 |
| **选择度 × 交火密度** Spearman ρ | **+0.3133**（p=0.0000682） | +0.2164（p=0.00372） |
| 　Pearson r / R² / p | +0.3320 / 0.1103 / 0.0000229 | +0.2473 / 0.0612 / 0.000875 |
| 整合度 × 交火次数（不按线长归一） ρ | +0.1227（p=0.127） | +0.2811（p=0.000144） |

## 口径与局限（三条）

1. 轴线图为**自动生成**（导航网格→骨架化→折线简化→端点吸附），Dust2 159 条 /
   Mirage 178 条；depthmapX 只负责分析。绝对值不可与人工描线的文献值直接比较，
   但两图使用同一算法，**图间比较成立**。
2. 交火点取"攻守位置中点"，密度按轴线长度归一；不归一的次数相关已列在表中。
3. depthmapX 对孤立轴线输出 integration=-1、choice=-1，已全部剔除（Dust2 剔除 3 条，
   对应交火从 1,533 减为 1,530）。
