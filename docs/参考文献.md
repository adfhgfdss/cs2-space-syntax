# 参考文献

写于 2026-09-19。这是给报告正文（`SPACE_SYNTAX.md`）直接配的文献表，用途有两个：
一是正文「方法 / 数据」「讨论」两章需要交代的出处；二是答辩或送审时的可核验凭证。

**核验方式**：除标 † 的那一条外，每一条都在 Crossref 上按 DOI 反查过题名、作者、
期刊、卷期页（2026-09-19 查），条内的 DOI 可直接解析。中文报告常见的 GB/T 7714
写法已在下面排版好，可直接粘进论文；正文引用位置建议见最后的对照表。

**编号说明**：`S` = 空间句法理论，`V` = 等视域 / 可见性图方法，`G` = 游戏与电竞空间
研究，`T` = 数据与工具。交稿前按正文出现顺序重编成 `[1][2][3]…` 即可。

> 另有一份 [参考文献核对.md](参考文献核对.md)，是逐条核对另一份外部 20 条清单
> （空间句法 + 游戏）的结果：哪里作者顺序错了、哪里卷期页错了，以及可直接粘贴的
> 修正版。两份合起来才是本报告的完整文献表。
