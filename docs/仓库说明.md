# 仓库说明：结构、怎么跑、什么没放进来

## 1. 脚本一览（都在仓库根目录）

| 脚本 | 作用 |
|---|---|
| `nav_extract.py` | 从本机 CS2 的地图包（`maps/<map>.vpk`）抽出导航网格 `.nav` |
| `vpk_extract.py` | 最小 VPK v2 读取器（`nav_extract.py` 依赖它） |
| `navmesh.py` | 解析 CS2 nav 版本 36（自实现），并与雷达图对位检查 |
| `heatmap.py` | 坐标变换（世界 ↔ 雷达像素），含 8 种轴向组合的自动判定 |
| `space_syntax.py` | VGA：连通度 / 等视域 / 整合度（拓扑与米制）/ 选择度 |
| `test_space_syntax.py` | VGA 实现的合成自检（5 个已知答案的形状） |
| `axial_map.py` | 自动生成轴线图（骨架化 → 简化 → 端点吸附）并导出 DXF |
| `depthmap_analysis.py` | **实验一 / 实验二**：调 depthmapX 算指标、交火对照、可理解度 |
| `exp_curves.py` | 曲线图（回归线、分位数曲线、累计曲线）与曲线数据表 |
| `extract_events.py` / `extract_tracks.py` | 单个 demo → 事件 / 轨迹（快速通道） |
| `ingest_demos.py` | 批量吃 demo：按地图自动分组，抽事件 + 轨迹，打来源标签 |
| `analyse_behaviour.py` | 构形指标 × 行为数据：相关、热点、分阵营 |
| `analyse_map.py` / `summarise_grid.py` / `verify_alignment.py` / `check_map_files.py` | 击杀/占位出图、网格汇总、映射校验 |
| `compare_maps.py` / `data_inventory.py` | 两图对比 / 数据体量盘点 |
| `run_all.py` | 一条命令跑完全流程 |
| `hltv_session.py` / `fetch_pro_demos.py` | 抓取 HLTV 职业赛 demo（可选） |

## 2. 环境

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
```

`requirements.txt` 里的版本是本仓库实测通过的组合（Windows + Python 3.12）。

## 3. depthmapX（实验一 / 实验二需要）

用官方 **命令行版**：`https://github.com/SpaceGroupUCL/depthmapX/releases`，
取 `depthmapXcli_win64.exe` 放到 `tools/depthmapXcli.exe`（仓库里没有该二进制）。

调用链（`depthmap_analysis.py` 已封装）：

```
IMPORT -it drawing          # 读入自动生成的轴线 DXF
MAPCONVERT -co axial -con axial
AXIAL -xa n -xac -xal -xar  # 整合度 / 选择度 / RA-RRA
EXPORT -em shapegraph-map-csv
```

两个坑：① depthmapX **把输入线直接当轴线**，端点不重合会被判为孤立线
（`integration=-1`），导出前必须做端点吸附；② 它的 CSV 列名带空格与方括号
（`Integration [HH]`），需要先归一化。

## 4. 原始游戏资产没有入库

雷达图、overview、导航网格的版权归 Valve：

* 导航网格：`python nav_extract.py de_dust2`（需本机装了 CS2）；
* 雷达图与 overview：见 `data/README.md`；
* 校验：`python check_map_files.py`、`python verify_alignment.py`。

## 5. demo 没有入库

20 场职业赛 demo 约 6.7 GB，且不宜随仓库分发。获取方式与命名规范见
`数据获取.md`。仓库保留了每场 demo 的元数据与 SHA256
（`out/behaviour/<地图>_meta.json`），便于核对样本来源。

## 6. 结果文件的读法

| 文件 | 关键列 |
|---|---|
| `out/<地图>_syntax_grid.csv` | VGA 逐格：`connectivity`、`isovist_area_px`、`integration_hh_t/m`、`choice_t`，含像素与世界坐标边界 |
| `out/<地图>_axial_lines.csv` | 轴线逐条：几何 `x1,y1,x2,y2`、`connectivity`、`integration_hh`、`choice`、`mean_depth`，以及 `crossfire`、`crossfire_per_m` |
| `out/<地图>_behaviour_grid.csv` | 逐格行为：`occ_all`、`occ_early`、`flow`、`kills_ct/t` 等 |
| `out/exp_fit_exact.json` | 两个实验全部回归的确切参数（n、ρ、r、R²、p、斜率、标准误） |
| `out/exp1_curve_data.csv` / `exp1_cumulative_data.csv` | 曲线上的确切数值 |
