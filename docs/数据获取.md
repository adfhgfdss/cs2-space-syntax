### 四条获取路径（按省事程度排序）

**路径 1：你自己的对局（最省事，推荐）**

如果你在 5E、完美世界、B5、FACEIT 这些平台打过，对局详情页通常有"下载 demo"
按钮：

| 平台 | 位置 |
|---|---|
| 完美世界竞技平台 | 对战记录 → 选中比赛 → 下载 Demo |
| 5E 对战平台 | 比赛记录 → 详情 → 下载录像 |
| B5 对战平台 | 战绩 → 对局详情 → Demo |
| FACEIT | 比赛页 → Demo 下载（需登录） |
| CS2 官方匹配 | 游戏内 Play → Your Matches → 下载 Demo（也可用下面的 CS Demo Manager） |

优点：完全不用账号验证、不用过验证码，直接就是 `.dem`。
缺点：需要你自己打过这两张图的对局。

**路径 2：CS Demo Manager（拉 Steam 上的官方匹配 demo）**

工具站：`cs-demo-manager.com`（开源项目 akiver/cs-demo-manager）。

1. 装好后打开，选 **Matches** 页；
2. 从 Steam 同步你自己的比赛列表；
3. 选中比赛 → Download → 导出成 `.dem`。

注意：它的安装包在 GitHub Release 上，你之前这台机器下 GitHub 附件会被重置；
如果下不动，告诉我，我可以试镜像站（API 和 raw 是通的）。

**路径 3：HLTV（职业赛，用于"职业比赛"口径）**

1. 浏览器打开 `https://www.hltv.org/results?content=demo`；
2. 找一场打过 **de_dust2** 的已结束比赛，点进去；
3. 页面 Maps 栏里每张图后面有 **Demo** 链接；
4. 下载得到 `.rar`，解压出 `.dem`。

必须用浏览器手动操作：**脚本会被 Cloudflare 挡住**（我今天用 curl_cffi 模拟
Chrome 试过，HLTV 返回 403 挑战页；bo3.gg 同样 403；archive.org 连不上）。
需要有 HLTV 账号（免费注册）。

**路径 4：赛事方/社区镜像**

如果你有惯用的 demo 站（比如某些赛事的官方 demo 包、社区镜像），直接把文件
给我也行；只要格式是 `.dem`（`.dem.bz2`、`.dem.gz` 我也能处理）。

## 六、你把 demo 给我之后，会发生什么

```powershell
# 1) 自动按地图分组、抽事件与轨迹（几场都行，重复跑会覆盖）
.venv\Scripts\python.exe ingest_demos.py --demos demos

.venv\Scripts\python.exe run_all.py de_dust2 de_mirage --demos demos --compare
```

产出会直接落到 `out\`：每图的 `_syntax_maps.png`（构形图）、`_behaviour.png`
（构形 × 行为）、`_behaviour.json`（相关系数），以及两图的
`compare_syntax_maps.png` / `compare_syntax_summary.csv`。
每一步都会自动存快照，出问题可以整目录回滚（`_history\HOWTO.md`）。
